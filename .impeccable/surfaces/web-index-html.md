# Surface brief: web app (Operate)

Scope: whole web app (project list, review workspace, lightbox). Mode: Operate. User: solo event photographer, desk, evening, keyboard-driven. Dark default, light available. Photo surround stays neutral grey in both themes. No icon-glyph stand-ins; icons are authored SVG.

## Direction contract
THESIS: Every shoot is a roll of film: film-box chrome (yellow, red, black) around neutral photos, frames numbered in edge-print code. Refuses the flat grey-plus-one-accent dashboard.
OWN-WORLD: Yellow #FFB300 top bar with red rule, black rail, off-white ink, orange edge-code mono for frame numbers and counters; Archivo Black display, Barlow Semi Condensed UI, Martian Mono data. Keep = green (matches the XMP Green label), reject = red, stars, pick outlines and group badges = yellow, selection = off-white ring. Light theme: cream-white body, same yellow bar.
STORY: User sees which roll (chapter) they are in, how many frames are decided, and keeps culling by keyboard without thinking about the chrome.
FIRST VIEWPORT: Yellow bar (name, search, segmented filter, counters, Best/All, theme) over a 300px black rail (settings, chapter rolls numbered 01A..., active one in full colour, others muted) and a neutral-grey grid whose captions show frame numbers like 14A and a keep/reject mark. Primary action (Index photos) sits in an action strip under the bar.
FORM: Film-stock packaging ranked 3 of 7 grounded candidates; signature move: edge-print frame captions plus digit-flip counters. seed:357e8e6c9be12b5c
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
